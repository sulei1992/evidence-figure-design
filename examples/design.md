# Three paired rendering trials

Each pair uses the installed R `datasets` tables, the same plotted observations or cells, identical numerical summaries and physical dimensions, and equal export settings. Conventional ggplot2 references use its light theme and readable labels. The redesigned figures keep exact input values and use a purpose-specific layout. These public-data fixtures are newly prepared demonstrations, not previously published user figures or a blind preference study.

All figures use Arial. Baseline text uses the same physical font and size budget as the redesign, with body/ticks at approximately 7–8 pt and slightly larger panel headers where applicable. Put statistics definitions and data provenance in a separate legend document. Reserve margins for labels and avoid notes at the bottom of the image. These sizes suit the trial tasks and are not intended as universal journal widths.

Read the new evidence-figure-design skill before rendering the redesigns. Integrity anchors from the original tables are 30 plants (10 each; means 5.032, 4.661, and 5.526), the Virginia rates 11.7 for rural males aged 50–54 and 50.0 for urban females aged 70–74, and 272 duration/wait pairs with waiting times 43–96 minutes. All source rows/cells enter both versions. Use double-sided 95% Student t intervals for the three separate group means (9 df each) and no significance tests. Plant symbols are defined in the companion legend. The mortality colour bar sits below the matrix with the original rate unit; it and the printed cell values allow independent reading. Shade only the fill in the data tiles, with a minimum 4.5:1 measured text-to-fill contrast. The geyser overview reads left to right with a 2.8:1 redesign panel width ratio, shared y scale 40–100 min, and fixed 5-minute bins closed on the left. Use 200-dpi PNG previews and editable SVG and PDF.
